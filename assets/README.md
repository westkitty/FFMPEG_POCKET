The older `dexcut-atlas.avif` was a **480 × 572 / 3.7 KB** experiment with only 160px artwork cells. It produced visibly degraded art when rendered on high-density phone displays and is no longer referenced by the application. Never reuse it.

The website's four sprite states are selected with a **200% × 200%** background-size grid and corner positions `0 0`, `100% 0`, `0 100%`, `100% 100%`. At the largest supported 310px display size, a 627px cell still provides more than 2 source pixels per CSS pixel.

The service worker and HTML use `-v2` asset paths and `dexcut-app-v2` cache naming. Keep subsequent artwork releases versioned to invalidate installed and browser caches.

## Regression guard

Run:

```sh
DEXCUT_PLAYWRIGHT=/tmp/dexcut-playwright/node_modules/playwright node tests/dexcut_artwork_qa.cjs
```

The test checks all 12 artwork originals/exports against exact Git content hashes, decodes active images at their native dimensions in Chromium, confirms 4 viewport layouts at DPR 3, validates the high-resolution mascot and header icon references, and verifies that the original 30 tools remain present.

Do not silently trade sharpness for extremely small files. Optimize web derivatives from the untouched PNG masters while retaining sufficient decoded source resolution; inspect the result on an actual high-DPI screen before approving future image changes.
