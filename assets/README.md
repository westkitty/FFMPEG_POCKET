# DEX//CUT production artwork

All character depictions follow the user-supplied canonical Dexter illustrations: floppy ears, black tricolor coat, cream chest and muzzle, tan eyebrows and cheeks, white forehead blaze, compact body, unimpressed expression.

- `dexcut-atlas.avif` — optimized 480×572 local sprite atlas, used by `dexcut.css` for stateful mascot expressions. Top row: idle (x=0,y=0) and processing (x=160,y=0). Middle row: restrained rage (x=0,y=160) and exhaustion (x=160,y=160). Each sprite is 160×160.
- `dexcut-poster.webp` — 1200×630 social/hero poster derived from the official DEX//CUT banner composition.

Browser icons (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`) are generated from the atlas idle artwork; the maskable icon uses an expanded safe-zone margin.

This art is part of the Stinky Weasel Productions identity. Do not substitute generic animals or change Dexter's distinctive markings. The red slash is a DEX//CUT brand treatment, not a replacement for the canonical mascot.
